# ReadReceiptBlocker

Un plugin **Vencord** axé sur la confidentialité, développé en **TypeScript**.

## Description
`ReadReceiptBlocker` intercepte les requêtes de confirmation de lecture (ACK) envoyées par Discord, te permettant d'ouvrir et de lire des messages sans les marquer comme lus pour l'expéditeur.
