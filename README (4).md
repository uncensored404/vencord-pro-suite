# MemberJoinLeaveTracker

Un plugin **Vencord** pour les modérateurs et administrateurs de serveurs, développé en **TypeScript**.

## Description
`MemberJoinLeaveTracker` surveille les événements de membres (Join / Leave / Ban) et affiche un flux d'alertes locales pour garder un œil sur le serveur sans encombrer les salons.
