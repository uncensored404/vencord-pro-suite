# Pack Pro Discord Suite (par 404sec)

Nouvelle collection de plugins TypeScript à forte valeur ajoutée pour Vencord.

## Plugins inclus :
1. **`ReadReceiptBlocker`** : Permet de lire les messages privés en toute discrétion sans déclencher l'accusé de lecture.
2. **`MemberJoinLeaveTracker`** : Outil d'audit et de suivi des arrivées/départs pour modérateurs.
3. **`CustomRichPresenceBuilder`** : Gestionnaire de statut et d'activité personnalisé intégrés.
